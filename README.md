# Áurea Studio

Site MVP de primeiro contato para o Áurea Studio (extensão de cílios, design de sobrancelha e tatuagem) — Valparaíso de Goiás, GO.

Prévia gerada como material de prospecção, baseada em leitura do perfil [@aureastudiooficial](https://www.instagram.com/aureastudiooficial/).

## Stack

- React 19 + Vite
- Tailwind CSS v4

## Rodando localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

O deploy para o GitHub Pages é automático via GitHub Actions a cada push na branch `main`.
